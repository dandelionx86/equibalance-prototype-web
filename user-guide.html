User Guide

Purpose of This Guide

This guide explains how to enter horse, forage, feed, and supplement nutrient information and how to review a nutrition summary with AI-supported explanations.

How to Use EquiBalance

1

Create Horse Profile

Add name, age, weight, workload, and body condition score.

  • Select Create Horse Profile.
  • Enter the horse’s name.
  • Enter the horse’s estimated body weight.
  • Select the horse’s age category.
  • Select the horse’s workload.
  • Enter the horse’s body condition score (BCS). (Optional)
  • Select Save Profile.
2

Add Feed and Forage Information

Enter hay, pasture, forage test data, and daily intake details.

  • Select Create Horse Profile.
  • Select Add Feed or Supplement.
  • Search for the product name.
  • Select the correct feed, ration balancer, or supplement from the results.
  • Enter the amount fed per day.
  • Confirm the serving unit.
  • Select Save Feed
3

Review Nutrition Summary

Compare major nutrient categories against estimated needs.

  • Open the horse profile.
  • Select View Nutrient Summary.
  • Review the forage, feed, and supplement totals.
  • Check for highlighted nutrient gaps (shown in red).
  • Check for highlighted nutrient excesses (yellow highlights).
  • Review calories, protein, vitamins, and minerals.
4

Read AI Explanation

Use plain-language results to understand possible gaps or concerns.

  • Read the plain-language summary of your horse’s nutrition profile.
  • Review the explanation of possible gaps or excesses.
  • Review the suggested next steps.

Note: AI-generated responses are not a substitute for professional veterinary or nutritional guidance. Always consult a qualified equine professional before making significant changes to your horse’s diet.

5
